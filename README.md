# XDLauncher

一个基于 Python 与 CustomTkinter 编写的轻量级、高性能 Minecraft 启动器。采用黑绿色现代深色 UI，纯原生下载引擎，开箱即用。

## ✨ 核心特性

- 🎨 **现代化界面**：微软雅黑字体，深绿色沉浸式主题，极简响应式布局。
- 🚀 **纯原生下载引擎**：支持多线程并发下载、超时重试、`.part` 断点续传、SHA1 完整性校验，保证游戏文件绝不损坏。
- 🌐 **国内网络优化**：Modrinth 模组/光影搜索下载走国内镜像站，告别搜索失败与高延迟。
- 🧩 **全量版本支持**：直接对接 Mojang 官方 API，实时拉取最新快照/远古版/正式版列表。
- 📦 **一键安装加载器**：后台自动检测当前版本支持的 Fabric / Forge / NeoForge，一键完成加载器部署。
- 🛡️ **自动补齐 Java**：如果电脑上没装 Java，启动器会自动下载并配置适配的 Adoptium JRE 17。
- 🎭 **整合包支持**：支持从 Modrinth 直接下载 `.mrpack` 整合包并自动解析安装。
- 🌍 **多语言支持**：内置简体中文 / English 双语，一键切换。

## 📥 如何下载与使用

### 1. 下载解压
- 在本页面下载最新的 **`XDLauncher.zip`** 压缩包。
- 将压缩包解压到你喜欢的任何文件夹（**请勿直接在压缩包内运行**）。

### 2. 启动
- 双击运行解压出来的 **`XDLauncher.exe`**。
- 首次启动如果提示缺少运行库，请允许程序自动配置。无需安装 Python 环境。

### 3. 第一次运行建议
- 去“设置”页确认一下“游戏目录”是否正确。
- 去“下载”页选择你需要的游戏版本（例如 1.20.1），并选择需要的加载器（如 Fabric）。
- 下载完成后，回到“启动”页输入你的用户名，点击启动。

## ⚠️ 杀毒软件误报说明（必看）

由于本程序使用了通用的打包技术，部分杀毒软件（如 360、火绒、Windows Defender）可能会将其**误报为病毒**或提示“未知发布者”。

**这是因为打包软件的压缩自解压行为特征与木马相似，属于正常误报，程序完全安全，无任何恶意代码。**
如果被拦截，请尝试以下操作：
1. 暂时关闭杀毒软件后再解压。
2. 将解压后的文件夹加入杀毒软件的“信任区/白名单”。
3. 如果是 Windows Defender 拦截，点击“更多信息” -> “仍要运行”。

## 🛠️ 常见问题 (FAQ)

**Q: 为什么启动游戏提示找不到 Java？**
A: 启动器默认会自动帮你下载 Java。如果下载失败，请前往“设置”页面，将 JAVA 选项改为“手动选择”，并手动选择你电脑上的 `java.exe` 路径（通常在 `C:\Program Files\Java\jre...` 下）。

**Q: 下载速度很慢怎么办？**
A: 原版游戏文件默认从 Mojang 官方服务器下载。如果网络环境特殊，建议开启代理或加速器。模组下载走的是国内镜像，速度较快。

**Q: 为什么点击“选择安装器”后要等一下？**
A: 因为程序正在后台联网检测 Fabric、Forge、NeoForge 的官方服务器，获取当前版本可用的加载器。界面不会卡死，请耐心等待几秒钟。

**Q: 配置文件保存在哪里？**
A: 启动器会自动在同目录下生成 `xd_launcher_config.json`，用于保存你的内存分配、窗口大小、游戏路径等设置。
